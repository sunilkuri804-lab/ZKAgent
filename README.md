# ZKAgent

On-chain AI Agent with ZK verification support (starter).

## Overview
ZKAgent is an early-stage on-chain AI agent vault.  
Users deposit funds and an authorized AI agent can execute verifiable actions on-chain.  
ZK proof verification is planned as the next milestone.

## Current Status
- Idea / Early Prototype
- Core vault smart contract ready
- ZK verification layer (planned)

## Tech Stack
- Solidity 0.8.20
- Hardhat
- Ethereum (Sepolia testnet ready)

## Next Milestone (Grant Use)
The grant will be used to:
1. Implement proper ZK proof verification for agent decisions
2. Secure key management for the AI agent
3. Deploy on testnet and run first autonomous actions
4. Add basic frontend for monitoring
